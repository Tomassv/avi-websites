With a workbook, the updater replaces the bodies of the seven tables above. Without one, it leaves the tables alone and only refreshes the SEO metadata, for example when archiving last month's report.
  • Percent columns are converted to values like 7.3%.
  • Pax estimates are formatted with one decimal place.
  • The latest available month is preselected automatically.
  • SEO: title, description, canonical URL, social sharing tags and structured data (Report, Dataset, breadcrumb) are rebuilt from the month and the key figures already on the page. Update the page copy and stat boxes first.
  • Current report points the canonical URL at report.html. Archive copy points it at the month's own file (for example october26.html) and downloads under that name.
